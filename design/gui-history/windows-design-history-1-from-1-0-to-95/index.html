    Windows 设计史 01：从青涩到成熟

    从 1985 年平铺窗口的 Windows 1.0，到 1995 年带着「开始」按钮和任务栏登场的 Windows 95。十年间，Windows 的界面怎样一步步长成今天我们熟悉的样子？

    Windows 的设计史不只是「抄苹果」：它向施乐 PARC 学过平铺窗口，请过 Susan Kare 画图标，而真正让它定型的，是 Windows 95 时代几十轮可用性测试里用户的真实反应。[1]

    01

    前奏：从「界面管理器」到「Windows」

    微软为什么要做图形界面，又为什么把它叫作「Windows」？

    1981 年，比尔·盖茨看到了第一台 Macintosh 原型机；1982 年 COMDEX 大会上展示的 Visi On 界面，进一步坚定了微软做自己的图形用户界面（GUI）的决心。和苹果一样，微软也选择向施乐（Xerox）「偷师」：1983 年 8 月，微软聘请了施乐 PARC 的首席开发者之一 Scott A. McGregor，为 MS-DOS 开发新的图形界面。

    这个界面最初只叫「Microsoft Interface Manager（微软界面管理器）」，给 BYTE 的测试软盘上又叫「Microsoft Window Manager」。McGregor 在施乐时就把自己的软件叫作「Windows」；营销副总裁 Rowland Hanson 也建议用这个词：用一个通用词当产品名，媒体提到时就不得不加上公司名，于是有了「Microsoft Windows」。

    可点击的时间线。点任意圆点（或用左右按钮）查看事件。上排是人物与事件，下排是版本发布。
    02

    Windows 1.0：蹒跚起步

    Windows 1.0 的窗口为什么是平铺的？真的只是怕侵犯苹果吗？

    IBM 当时在做自己的同类项目 TopView，对微软的 Windows 并不感冒。微软 1983 年 9 月在 BYTE 杂志上展示原型、11 月在 COMDEX 演示，宣称 1984 年 4 月发布，却一再延期，得了个「Vaporware（雾件）」的名号。直到 1985 年 11 月 20 日，Windows 1.0 才正式发布。

    它最大的界面特点是平铺窗口，而同期的 Macintosh 用重叠窗口。网上常说这是「怕侵权苹果」，但施乐 PARC 早在 1981 年的 Cedar 项目里就用了平铺窗口，微软很可能是研究它之后做的选择。McGregor 本人说：「Windows 从一开始就具有重叠窗口的功能……反而在此基础上编写平铺管理器的工作量要大得多！」原版 1.0 的弹出窗口、菜单和下拉菜单本来就是重叠的，给 BYTE 的版本也是重叠窗口，后来还有人修补 1.0 的界面库让它重叠起来。[1][7]

    窗口最小化（图标化）后，图标排在屏幕底部，类似的设计后来被任务栏继承。

    平铺 vs 重叠。点「打开程序」加窗口，切换两种模式对比。窗口标题栏右侧的小方块是最小化，最小化后图标落到底部那一排，点图标还原；重叠模式下点窗口可把它提到最前。

    平铺的特点也体现在 1.0 的 Logo 上：像四个平铺在屏幕上的窗口。几十年后 Windows 11 的 Logo 又回到了四方格，算是回归「窗口」的本源。

    作为初代产品，1.0 的图形元素比较粗糙。同样是 32×32 像素网格、黑白配色，它的图标远不如 Macintosh 的优雅，有些图标还缺乏辨识度，比如控制面板和日历，都是分成几块的矩形。少有的亮点是时钟图标：它会跟着当前时间走。微软还做了 Windows 的第一款游戏「黑白棋（Reversi）」，不过名气远不如后来的纸牌和扫雷。

    考考辨识度。下面是按原文描述重绘的三个 1.0 风格黑白图标（32×32，放大显示）。左边两个哪个是「控制面板」？第三个是实时走动的时钟图标。

    总的来说，Windows 1.0 引起了一定关注，但不算成功：评论批评它系统要求偏高，而且依赖鼠标，对键盘用户不够灵活。

    03

    Windows 2.x：不温不火

    2.x 改了什么？为什么又没改出多大名堂？

    1987 年 12 月，Windows 2.0 发布。设计上最大的变化是重叠窗口取代了平铺窗口（上一章演示里的「重叠」模式），由此引发了苹果与微软那场著名的诉讼，最终判决对微软有利，Windows 得以继续用重叠窗口。平铺窗口并没有就此消失，十几年后它还会以新姿态回到 Windows 里。

    除此之外，2.x 的图形界面改动有限，图标、控件基本沿用 1.0，市场反响一般。

    本页补充（非原文）：这场诉讼即 Apple Computer, Inc. v. Microsoft Corp.。苹果于 1988 年起诉，指控 Windows 2.0 等抄袭 Macintosh 的「外观与感觉」；地区法院认定绝大多数被诉元素属于 1985 年苹果授予微软的许可范围或不受版权保护，1994 年第九巡回上诉法院维持了对微软有利的判决。[9]
    04

    Windows 3.x：从一个玩笑开始

    3.x 的界面到底变了哪些，让它成为第一个商业成功的 Windows？

    1988 年 6 月下旬一个周五晚上，微软工程师 Murray Sargent 在聚会上取笑朋友 David Weise：你们的 Windows/286 内存管理太糟了，应该进保护模式、打破 640 KB 的限制。没想到 David 当场拉他回园区，一番尝试后真把 Windows 2.0 启动到了保护模式。这个方案在 3.0 的开发会议上获得通过，Windows 3.x 就此开始。[6]

    界面上，程序管理器（源自 OS/2 的 PMShell）取代「MS-DOS 执行程序」成为默认外壳，文件管理功能交给「文件管理器」；MS-DOS 执行程序在 3.1 里被彻底删除。

    本页补充（非原文）：Windows 3.0 发布于 1990 年 5 月 22 日，3.1 发布于 1992 年 4 月 6 日。[8]

    Susan Kare 的图标：有了颜色和阴影

    为 3.x 设计图标的，正是曾为 Macintosh 设计图标的 Susan Kare。经她整改，3.0 的图标更成熟、辨识度更高，并有了颜色（16 色）和阴影；3.1 里她又加了更多色彩，还设计了纸牌游戏的卡面。到了 Windows 95，部分图标改用类似苹果 Copland 风格的等轴测视图，仍是 32×32、16 色；后来的 Microsoft Plus! 附加包才引入 256 色图标。[1][12]

    同一个「电脑」图标，四种画法。选一个时代，看 32×32 网格上的变化：黑白线条 → 16 色加投影 → 等轴测 → 256 色。图标先按矢量画出，再现场量化到对应调色板，状态栏统计实际用到几种颜色。图标为本页示意，非原版位图。

    Logo：从一扇窗户到一面旗

    3.0 的 Logo 最写实：一扇黑白窗户。3.1 引入了经典的「四色块」，由高级副总裁 Brad Silverberg 委托、Jonathan D. Cowles 在 Jeff Boettcher 和 Julie Wong 监督下设计。按 Brad 的说法，右边象征「窗口」，左边加了运动效果，整体看又像一面旗帜。此后四色块成了微软的标识，用在 Office、MSN 上，2012 年至今的微软 Logo 也采用了四色块。

    TrueType、壁纸与「立体」的按钮

    字体方面，3.1 采用了 TrueType，加入 Times New Roman（兼容 Times Roman）、Arial（兼容 Helvetica）、Courier New（兼容 Courier）等新字体，提高了文字的辨识度。3.0 还是第一个支持壁纸的 Windows：此前只能设背景色，现在可以用平铺图块或全屏图片。

    位图字体 vs 轮廓字体。选一个字体，拖动字号。左边模拟只做了 12 像素一个尺寸的位图字体被硬放大；右边是浏览器用本机 TrueType 字体按字号重新渲染。（若本机没装该字体，会回落到同类字体。）
    本页补充（非原文）：TrueType 是苹果在 1980 年代末开发、授权给微软的轮廓字体格式：字形用曲线描述，任何字号都按轮廓重新栅格化，所以不会像只为固定尺寸画好的位图字体那样一放大就出锯齿。[10]
    像素级放大镜：按钮的「立体感」从哪来。选一种按钮画法，按住画布里的按钮看按下状态；把鼠标移到像素上，状态栏会说出这一格是什么颜色、起什么作用。
    本页补充（非原文）：原文没有展开控件画法。这里按常见复刻的配色示意：1.0/2.x 的控件基本是黑线白底的平面；3.x 起按钮变成灰底，左上亮、右下暗，靠一两像素的明暗边模拟凸起；95 把边框整理成两层（外层白/黑、内层亮灰/灰），按下时明暗互换、文字右下移一格。具体像素以实机为准。

    纸牌与扫雷：伪装成游戏的鼠标课

    为了让用户熟悉鼠标、也让 Windows 更好玩，3.0 加入了纸牌，教人练习「拖放」；3.1 里扫雷取代黑白棋，教人用好鼠标的左右键。

    两节鼠标课。纸牌：把红心 A 拖到收牌区。扫雷：左键翻开，右键（手机上长按，或打开「插旗模式」）插旗。

    3.x 被认为是第一个取得商业成功的 Windows，也是第一个有中文版的 Windows。3.1 已有简繁中文版，微软又为中国市场推出了 Windows 3.2，加入郑码、智能 ABC 等更多中文输入法。

    05

    Windows 95（上）：从「开罗」到「芝加哥」，先听听用户

    3.1 的界面到底哪里难用？微软最初的修补方案为什么失败？

    3.x 的一个突出问题是：打开的窗口，包括最小化后的图标，都可能被别的窗口盖住，许多用户找不到自己开过的程序，只好再开一份，最后耗尽内存；程序管理器也不够直观。重新设计始于一个叫「开罗（Cairo）」的项目，本来是为了改进 Windows NT，后来它的界面设计被用到 3.1 的下一版，代号「芝加哥（Chicago）」。目标是：老用户容易上手，新手也能轻松上手。著名的失败品 Microsoft Bob 也是那时的产物。

    据设计团队成员 Kent Sullivan 的报告《Windows 95 用户界面：可用性工程案例研究》，开发期间微软做了这样的测试：[2]

    560名受试者
    64个测试阶段
    50%是 3.1 中等水平用户，其余为新手、高手和其他系统用户
    > 9.5 分钟新手在 3.1 里找到并打开一个不立即可见的程序的平均用时

    除了高水平用户，所有人都不了解如何有效管理重叠窗口。一开始，顾及 3.1 用户的适应成本，微软的步子迈得很小。下面是 Cairo/Chicago 早期版本的界面模型。

    早期模型 vs 最终设计。点图上的部件看说明；切换到「Windows 95」看这些部件后来变成了什么。按原文描述示意重绘。[1][5]

    早期版本的测试结果同样不理想：用户会搞混左下角三个按钮，找程序的速度和窗口管理效率也没什么提升。许多用户的反馈是：「新版本 Windows 只是不同，而不是更好。」

    于是团队放开手脚：不再执着于和 3.1 保持一致，转而把重心放在体验上，并加快迭代，在更短时间里试更多新想法。

    06

    Windows 95（中）：「发现水的不一定是鱼」

    「开始」按钮和任务栏，分别在解决测试里发现的哪个问题？

    1992 年，行为心理学家 Daniel Oran 加入微软参与界面设计。他此前一直用苹果电脑，刚来时连 Windows 都用不顺。他后来说，引用了媒体理论家麦克卢汉的话：「发现水的不一定是鱼。」正因为没深入用过 Windows，他能看到老用户注意不到的东西。[3]

    可用性测试的结论有三条：

    1. 新手和一些中级用户用鼠标很吃力，尤其是双击；需要双击才能打开的东西，他们常常束手无策。
    2. 他们几乎完全依赖看得见的提示找命令：用菜单栏和工具栏，但不用右键菜单这类弹出菜单，培训后也一样。
    3. 窗口管理的主要问题是：窗口并非始终可见，用户没法快速看到自己开了什么。

    Daniel 先做了一个叫 ClearView 的新手界面：全屏选项卡，用来启动程序、打开最近文档和切换窗口。测试结果不错，但局限明显，最后放弃了（二十多年后，类似的「Windows Sets」只在几个 Windows 10 测试版里昙花一现）。不过它的优点留了下来：单击即可访问、高可见性、基于菜单的交互，「开始」菜单就是这样设计出来的。

    「开始」按钮原名「系统（System）」，Daniel 觉得太专业，改成了「开始」；首次启动时，按钮旁还会提示「Click here to begin（单击这里开始）」。

    找程序计时赛。任务：打开「计算器」。先在 3.1 的程序管理器里找（打开群组和程序都要双击），再在 95 的开始菜单里找（全程单击）。比较两边的点击次数与用时。

    针对「窗口并非始终可见」，微软把每个打开的窗口固定成屏幕上的一个条目，也就是任务栏：每个任务一颗按钮，任务栏位于所有窗口之上。任务栏起初沿袭选项卡的设计，默认在屏幕顶部；但测试发现有些程序默认可用区域从 (0,0)（左上角）开始画，会和任务栏打架，也可能是为了避开和苹果顶部菜单栏相似，最终默认放到了底部。[1][4]

    开了几个程序，还看得见几个？多点几次「再打开一个」，再把一些窗口最小化。3.1 模式下最小化的图标落在桌面上，会被窗口盖住；95 模式下它们都在任务栏里。95 模式还可以把任务栏挪到顶部，看看左上角那个「老程序」会怎样。

    微软内部也有人不认同这套界面：有高管觉得任务栏按钮太像汽车上的电台按钮，也有人只是不喜欢「开始」这个名字。但可用性测试的结果最终说服了他们。

    07

    Windows 95（下）：最终发布

    一个设计决定，怎样变成了操作系统史上最大规模的发布营销之一？

    1995 年 8 月 24 日，Windows 95 发布。微软放弃了 1.0–3.x 的版本号命名，改用年份。为了宣传「开始」功能，微软买下滚石乐队的《Start Me Up》（价格说法不一：流传过 1200–1400 万美元，可能是乐队成员编的；一位前微软首席运营官说接近 300 万美元），还请 Jennifer Aniston 和 Matthew Perry 拍了喜剧形式的视频教程，「开始」是电视广告的宣传重点。[1][11]

    结果大获成功：四天内全球销量 100 万份。彼时苹果正陷在 Pink 项目和 Taligent 的泥潭里，Windows 95 吸引了更多媒体关注，市场份额不断上升，最终让 Windows 主导了操作系统市场。

    除了桌面，微软还依据测试结果重做了「打开/另存为」「选择打印机」等对话框，其中一些设计沿用至今；图标也改进了，部分采用等轴测视图（见第 04 章的图标演示）。

    Daniel Oran 在 95 发布前就离开了微软，当时并不确定「开始菜单 + 任务栏」会不会被采用。结果它不仅进了 Windows 95，成了此后 Windows 界面的基础，还影响了 KDE、Xfce 等桌面环境。他说：「这真是太棒了，几乎不可思议。在 1993 年我绝对不会想到这一点。」

    08

    念念不忘：Windows 3.x 留下的遗迹

    如果用户就是想要回 3.1 的界面，Windows 95 给了哪些退路？

    微软还是不放心：万一有人不适应新界面呢？安装 Windows 95 时，可以选 3.1 的「程序管理器」作为默认界面。但那样得到的只是一个默认打开程序管理器的 95 桌面；想要真正接近 3.1 的体验，得把 system.ini 里的 shell 改成 progman.exe。完整的程序管理器在 Windows XP SP2 之后才被移除；靠 Windows 的向后兼容，移植旧版程序管理器至今仍能在新系统上跑起来。
