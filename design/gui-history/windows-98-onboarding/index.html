Windows 98 的新用户引导
    设计 · GUI 史 · 用户引导

    二十年前的 Windows 98，新用户引导做得比很多今天的产品好

    注册不强求，上网设置可以晚点再说，默认选项替你做完大部分决定，不会用鼠标就先做几个小练习。这页把原文里提到的每一招都画成能点的线框，你可以亲手从「欢迎使用 Windows 98」走到桌面。

    好的新用户引导（onboarding）不靠厚手册，靠的是：少问、晚问、给默认值、让人边做边学、随时能跳过，并且不对用户的水平做任何假设。Windows 98 在 1998 年就做到了这些。[1]
    BBenjamin Brandall（原作者） 优优设网（中译，陈子木）

    原文：Benjamin Brandall，〈Why Windows 98's User Onboarding is Better Than Yours〉，Usersnap 博客（2016-09-27）；中译〈20年前的Windows 98，有一套不俗的新用户引导流程〉，优设网（uisdc.com）。本页忠实于原文的叙述顺序，界面截图均改为示意线框（不是像素还原），并加了几处标注为「本页补充」的核对与延伸。

    01

    第一次开机，你看到的是什么

    同样是「刚装好系统」，Windows 3.1 和 Windows 98 给新手的第一眼差在哪？

    作者说，今天读微软当年的界面文档就像考古：设计者和开发者手里有一本 381 页的指南。和「混乱粗陋」的 Windows 3.1 比，Windows 98 的进步一眼可见。3.1 进去之后是一堆程序组图标，没有任何「从这里开始」的提示；98 则在第一次启动时弹出一个欢迎窗口，把注册、上网、学习、维护四件事摆在你面前，每一件都可以不做。[1]

    切换两个系统的首次开机画面（示意线框）。点画面上的东西，看系统有没有告诉你下一步该干什么。
    本页补充（非原文）：英文原文说的「381 页」是微软 1995 年出版的《The Windows Interface Guidelines for Software Design》，写给给 Windows 开发应用程序的设计师和开发者，不是给 98 准备的「引导内容」；中译把它说成「1998 年的用户界面」和「为整个系统准备的 381 页引导内容」，略有偏差。[1][3]
    02

    先看今天：注册表单、空状态、交互教学

    硬件强了二十年，好引导的原则变了吗？

    作者先举了几个当下的例子：Process Street 的注册页（字段少，可用第三方账号）、Spotify 和 Trello 的空状态（没有数据时告诉你为什么空、怎么填）、GitHub 和 TeamGantt 的入门（用真实示例项目和提示框带你走一遍，而不是丢给你一份手册）。他的结论是：限制少了，可能性多了，但原则没变。[1]

    三条原则，各看一组「反例 / 正例」。原文的产品截图在这里改成了不带品牌的示意线框。
    03

    渐进式档案：一次只问一点

    Windows 98 什么时候才向你要信息？

    原文把 Windows 98 的做法叫作渐进式档案（Progressive Profiling）：把建档要填的信息拆散到使用过程中的不同时刻，避免一上来信息过载。注册不是强制的；作者第一次被要求设密码，是在第一次注销的时候；调制解调器（当年拨号上网用的「猫」）也可以等到第一次打开 Outlook 或 IE 需要联网时再设置。[1]

    同样三件事，换个时机问。切换模式，看进入桌面之前你必须面对几项。
    04

    回收站：一个贴心的空状态

    一个系统里几乎没有空白页面，那空状态该在哪里练手？

    Windows 98 自带大量快捷方式和文件，几乎看不到完全空着的界面。回收站是例外：它经常被清空。扔进去、还原、彻底清空，这套动作和现实中的废纸篓一样好懂，左侧边栏的说明文字再把正确用法讲清楚。[1]

    删几个文件试试：点桌面上的文件把它扔进回收站，再在回收站里还原或清空，留意左侧说明怎么随状态变化。
    05

    便捷的默认设置：典型安装

    不想做选择的人，最少要做几个决定才能装好？

    如果你不想一项项定制组件，选「典型安装」就能快速完成。和 Windows 3.1 不同，98 已经替普通用户准备好一套起步组件，让人走阻力最小的路，不必做太多决定。[1]

    模拟安装程序的「安装类型」一步。切换选项，看你接下来还要回答多少个组件问题。
    本页补充（非原文）：原文只提到「典型安装」与可定制两条路。Windows 95 的安装程序提供 Typical / Portable / Compact / Custom 四种类型，98 沿用了同样的安装类型（无人值守安装参数 InstallType 里 0 对应 Compact）；本页线框据此画出四项。组件清单为示意，不是 98 的完整组件表。[5][6]
    06

    通过小练习学会使用 Windows 98

    不会用鼠标的人，怎样在不被系统「控制」的情况下学会它？

    有的用户已经会用键盘鼠标，有的还不会。原文引用 GUI 设计准则：「用户应当始终感到自己在控制软件，而不是被软件控制。」所以 98 用一串小练习带新手熟悉鼠标和键盘；觉得自己会了，随时可以跳过；最后还有个小测验，看你练完理解了多少。[1]

    可点击的「欢迎使用 Windows 98」重演（示意线框）。左侧四项都可以点：注册和上网都能推迟，「探索 Windows 98」里有三个鼠标小练习和一个测验，任何时候都能跳过。
    本页补充（非原文）：原文没有画出欢迎窗口本身。据微软《Windows 98 Getting Started Guide》，欢迎屏在 Windows 98 首次启动时出现，提供「现在注册」（Register Now）、「连接到 Internet」（Connect to the Internet）和「探索 Windows 98」（Discover Windows 98，涵盖计算机基本技能、Windows 98 基础与新功能、更多资源）等入口；第四项「维护您的计算机」（Maintain Your Computer）来自二手资料。本页练习内容为示意，不是对原版教程的逐屏还原。[4]
    07

    把电脑比作打字机和电视

    为什么 98 要把电脑类比成你家里已有的东西，而今天的系统不这么做了？

    1998 年电脑远没有今天普及，微软在引导里把电脑和用户熟悉的东西放在一起讲：屏幕像电视，键盘像打字机。原文给出的数字是：那时 64% 的美国家庭没有电脑，到原文写作时只剩 16%。作者把这和拟物化（Skeuomorphism）联系起来，并引用 Tim Worstall 的定义：物件保留了过去版本的装饰性元素，而这些元素对功能并无加成。拟物在乔布斯时代的苹果很流行，iOS 7 之后才转向。作者认为 98 谈不上一套系统的美学，但它借用用户已有的经验，正是它的界面元素好认的原因；今天大家都熟悉这些元素，自然不需要这种引导了。[1]

    点卡片翻面：左边是电脑里的概念，翻过来是 1998 年的新手已经熟悉的现实物件。
    美国家庭电脑拥有率（本页补充，美国人口普查局数据）。点年份看当年「没有电脑的家庭」占多少。
    本页补充（非原文）：原文的 64% 没有注明出处。美国人口普查局 1997 年 10 月的调查显示，36.6% 的家庭拥有电脑（1984 年 8.2%、1989 年 15.0%、1993 年 22.8%），即约 63% 的家庭没有，与原文的 64% 基本一致。原文的「16%」指写作时（2016 年前后），本页没有找到对应的原始数据，图中以虚线柱标为原文数字。[7]
    08

    是什么让 Windows 98 进步这么快

    为什么「不要随便改动用户已经熟悉的元素」这条规矩这么重要？

    作者认为，3.1 与 95/98 之间的质量差距，从文档上就能看出来：3.1 时期的设计者对用户体验的理解远不如后来深入。1995 年的 Windows 界面指南写道：

    除非界面原本不支持某项功能，否则不要添加新的元素或行为。更重要的是，避免改变现有的常见元素和行为。用户对界面怎么运作是有预期的，不一致会让人困惑，也会增加界面的复杂度。[1][3]
    一致性小测：每一轮都请你点「取消」。先在「按惯例」模式下点 6 轮，再换「每次都变」模式，比较平均用时和点错次数。
    09

    不对市场做过高的假设

    一个引导流程，怎么同时照顾老手、3.1 用户、Mac 用户和从没摸过鼠标的人？

    原文的结论：98 能把系统设计提到新高度，很大程度上是因为微软没有对用户做过高的假设。简短设置之后就能用；有经验的人可以轻松跳过教程，没用过的人能在练习里快速上手；Windows 3.1 用户、Mac 用户、从没用过键盘鼠标的人，各有单独的帮助。[1]

    选一种身份，看 98 的引导给你安排的路线（示意）。
    作者在文末对比了被他妈妈称为「垃圾」的 Windows 8：它忽略了许多设计准则，对用户预设太多。想做出真正好的体验，设计师要有同理心；用户没法快速上手，就会很快离开。
