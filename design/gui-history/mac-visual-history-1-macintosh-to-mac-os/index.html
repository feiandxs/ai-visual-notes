    Mac 视觉史（一）：从 Macintosh 到 Mac OS

    1984 年的 512×342 黑白屏，到 1999 年带拉丝金属的 Mac OS 9：Classic Mac OS 十五年的界面怎样一步步长出颜色、光影和层次，名字又是怎样从「没有名字」变成 Mac OS 的。

    Mac 的图形界面始于施乐，成于乔布斯，在迭代中一步步完善：第一个系列在交互框架上高度延续，一直在模拟现实世界的元素，并在当时的屏幕条件下尽量提供最好的视觉体验。[1]
    拖动年代滑块：同一张桌面在七个版本里的示意线框（不是截图还原）。橙色虚线框标出这一版相对上一版的变化；点右下角垃圾桶试试它有几种状态。

    原文：《Mac 视觉史（一）：从 Macintosh 到 Mac OS》，陈子木，少数派（2020-05-19），首发于优设网，原题《Mac 视觉史 vol.1：从 Macintosh 到 Mac OS》。本页按原文的章节顺序讲解，原文中的界面截图全部改为示意性的线框与色块重绘；另加了几处标注为「本页补充」的核对与延伸。

    01

    两大系列，四个名字

    我们口中的「Mac 系统」到底指哪个系统？它在不同年代分别叫什么？

    原文先把 Mac 系统分成两大系列：随 Macintosh 发布、一直到 1999 年 Mac OS 9 的第一个系列，统称 Classic Mac OS；2001 年之后的 Mac OS X 系列（X 是罗马数字 10）包括今天的 macOS，是第二个系列。名字则先后有四个：Macintosh、Mac OS、Mac OS X（中间有一段叫 OS X）、macOS。

    点色条或下面的名字，看每个名字覆盖了哪些版本、为什么改名。色条宽度按年份比例画。
    本页补充（非原文）：原文写「1982 年随 Macintosh 发布的系统」，但第一台 Macintosh 是 1984 年 1 月 24 日开售的，Classic Mac OS 的起点应为 1984 年。原文注释里「OS 本就是 Operation System 的缩写」应为 Operating System（原文评论区已有读者指出）。「Mac OS」标志最早出现在 System 7.5.1 的启动画面上，7.6 版正式改名 Mac OS。[2][5]
    02

    图形化界面：向施乐偷师

    Macintosh 不是最早的图形界面，那它比前辈强在哪里？

    通行的看法是，图形用户界面来自施乐帕罗奥托研究中心（Xerox PARC），最早使用图形界面的电脑是当时还在研发中的 Xerox Alto。比尔·盖茨曾指责乔布斯从施乐「偷」走了 GUI，但原文指出：乔布斯去 PARC 观摩 Alto 和开发工具 Smalltalk 的机会，是拿股权换来的。原文的评价是，Alto 的界面的确图形化了，但用今天的眼光看「整体的界面逻辑并不清晰」；Macintosh 在设计细节和实现上后来居上。

    示意对比：左边是 Alto 上 Smalltalk 环境的典型布局（竖屏、多个文字窗格互相叠放、菜单要在窗格里弹出），右边是 1984 年 Macintosh 的布局（顶部固定菜单栏、带标题栏的窗口、桌面图标）。两张都是线框，不是截图。
    本页补充（非原文）：Alto 于 1973 年在 PARC 完成。乔布斯 1979 年带 Apple 工程师参观 PARC；与之相关的交换通常被描述为施乐获准在苹果上市前认购一批苹果股票（本页凭记忆补充，未逐一核对具体股数与金额）。Macintosh 的「固定在屏幕顶部的菜单栏」与 Alto 上 Smalltalk 的弹出式菜单是两种不同的思路。[5]
    03

    规避纠纷：Macintosh 的名字来源

    为什么是「Macintosh」，而不是那种苹果本来的拼法「McIntosh」？

    1979 年，项目发起者 Jef Raskin 想用自己最喜欢的苹果品种 McIntosh 命名。但纽约有一家做高端音响的公司叫 McIntosh Laboratory，为避开商标冲突，Raskin 把拼写改成 Macintosh，「故意错开了一个字母」。

    逐字母对齐：橙色是两种拼写不一样的位置。

    1984 年 Macintosh 上市。主板由 Burrell Smith 设计，屏幕是一块 512×342 的单色显示屏。原文说，在这块「寸土寸金」的单色屏幕上，系统要把图形界面的价值尽量发挥出来。下面算一算这块屏幕到底有多「贵」。

    选一种屏幕：矩形按真实像素数同比例画出；数字在页面里现场计算。帧缓冲大小 = 宽 × 高 × 每像素位数 ÷ 8。
    本页补充（非原文）：Macintosh 128K 的屏幕为 9 英寸单色 CRT，512×342 像素、72 像素每英寸，主板由 Burrell Smith 设计，1984 年 1 月 24 日开售，售价 2495 美元。[5]它没有独立显存，屏幕缓冲占用的就是那 128 KB 主内存的一部分。Alto 屏幕 606×808、Macintosh II 的 640×480 与 256 色是本页凭记忆给出的参考值，未逐一核对。
    04

    Macintosh 系统：正式拥有姓名

    Macintosh 电脑名满天下的时候，它的操作系统叫什么？

    答案是：没有正式名字。1.x 系列只有一个非正式的称呼 System 1，之后的大版本也顺着叫 System 2、System 3……直到 System 5，这个系统才算正式有了 Macintosh 的名字，完整名称是 Macintosh System Software。

    05

    System 1 - System 5：功能迭代

    受限于屏幕和性能，System 1 到 4 的外观差别不大。那这几代到底在变什么？

    System 1 开机有一个可爱的欢迎界面；菜单与窗口的概念清晰，比 Alto 成熟；左上角的苹果图标打开后本质上是一个程序列表；出错时报错界面用炸弹图标提示（原文说 1984 年的崩溃界面比 2000 年后的 Windows 蓝屏有趣）；Macintosh 还从一开始就为自己设计了一系列字体，其中的 San Francisco 多年后还有了一款同名的系统默认字体。

    触发一次「系统错误」：线框示意那个带炸弹的报错框。

    原文特别提到：在 System 1 里，文件夹是一个虚拟概念，文件系统中根本不存在文件夹，它只是模仿现实文件夹的界面概念；到 System 3，文件夹「也不再只是一个虚拟的概念了」，垃圾桶也有了「有文件」和「已清空」两种状态（顶部滑块切到 System 3 点垃圾桶可见）。

    同一个 Finder 窗口，磁盘上怎么存？切换文件系统，再点左侧任一文件，看它在磁盘上的位置。
    本页补充（非原文）：System 1 用的是 MFS（Macintosh File System），一个平面文件系统：磁盘上所有文件在同一层，文件夹只是 Finder 为每个文件记下的「显示在哪个文件夹里」的信息。之后的 HFS（Hierarchical File System，层级文件系统）才在磁盘上真正建立目录树。平面结构的一个后果是同一张盘上不能有两个同名文件，即便它们「在」不同文件夹里（本页凭记忆补充，未逐条核对）。

    从 System 1 到 System 4 功能一代代增加，图标和界面细节越来越丰富，比如控制面板就比 System 1 时代丰富许多。System 5 加入了多任务功能 MultiFinder，用户终于可以同时运行多个任务，不过受性能限制，跑多任务时会比单任务慢不少。

    本页补充（非原文）：MultiFinder 是协作式多任务，在 System 5、6 中可选；System 7 起成为强制的默认模式，正在运行的程序列表也从苹果菜单移到了菜单栏右侧单独的「应用程序菜单」。[3]
    06

    System 6：集大成的版本

    黑白时代的最后一个大版本，它「集」了什么？

    原文称 System 6 是阶段性集大成的版本：系统版本与软件版本在 System 6 统一，功能也相当完善。性能更强的 Macintosh SE/30 和笔记本 Macintosh Portable 也是在 System 6 更新期间发售的。在顶部滑块里，System 5/6 的变化是菜单栏右侧多了一个表示当前程序的小图标（MultiFinder）。

    07

    System 7：拥有色彩的新世代

    1991 年黑白界面时代结束。有了颜色，界面设计多了哪些能力，又暴露了哪些问题？

    从 System 7 开始，Macintosh 有了彩色界面：图标拟真度再次提升（垃圾桶的光影已经相当逼真），用户可以按偏好做全局色彩设置；软件安装的进度指示清晰明确；重要信息标红强调；受分辨率限制，按钮的阴影与凸起做得比较简单，但整体始终在模拟现实元素（计算器、键盘最典型），以减轻认知负荷；系统还内置了交互式帮助。

    全局色彩设置：选一种高亮色和窗口色，看示意窗口与选中的文字如何一起变。

    原文也指出了问题：控制面板的图标统一性提升了，风格有时代特征，但「信息的传达还不够优秀，如果没有文本标签，你很难判断每个按钮对应的功能是什么」。

    不看标签猜功能：下面是 8 个控制面板风格的示意图标（本页自绘，不是原图）。先猜，再点图标揭晓；也可以一键显示全部标签。

    System 7 这一阶段，大量兼容机和包括 Windows 在内的操作系统涌现，苹果在激烈竞争中推出了一系列新 Macintosh，也想出了新策略，这一策略促成 Macintosh 系统后来成为独立品牌。

    本页补充（非原文）：System 7 于 1991 年 5 月 13 日发布，新特性列表里写的是「为支持彩色的机器提供新的彩色化界面」；原文说的「交互式帮助系统」即气球帮助（Balloon Help），鼠标悬停时弹出说明气泡，类似今天的工具提示。[3]彩色显示的硬件支持早于 System 7（1987 年的 Macintosh II 已能显示彩色），System 7 是让系统界面本身彩色化（此点本页凭记忆补充）。
    08

    Mac OS：第一次品牌重构

    非苹果生产的电脑也能跑 Macintosh 系统，那开机画面上该写什么？

    为应对竞争，这一阶段的 Macintosh 逐步换用 PowerPC 架构的 CPU，苹果还授权第三方厂商用同架构的芯片和主板，安装 System 7（例如 StarMax 兼容机）。于是问题来了：非苹果的电脑上也会显示「Macintosh」字样，怎么和原装机区分？办法很简单：原装机上依然写 Macintosh，兼容机上则是「黑苹果」：Mac OS。

    切换机器，看启动画面的区别（线框示意）。

    原文说，当时很多人以为这只是临时的差异化方案；而乔布斯即将重掌苹果，打算终结前 CEO 的第三方授权策略。改名 Mac OS 就是解决方案，「只不过这个解决方案后面还有其他的深意。因为后面还有新系统。」

    本页补充（非原文）：Mac 兼容机（clone）主要出现在 1995 至 1997 年间，乔布斯回归后终止了授权计划。[2]原文写「1996 年乔布斯重回苹果」：1996 年底苹果宣布收购 NeXT，乔布斯随之回到苹果。
    09

    Mac OS 8：一石二鸟的更新

    一个本该叫 7.7 的版本，为什么直接叫 8？

    Mac OS 8 于 1997 年 7 月 26 日发布。原文说它并非真正意义上的大版本更新，原本应该是 Mac OS 7.7；但前 CEO 与第三方厂商签订的授权协议基于 Macintosh System 7，直接发布 8.0，就等于借命名把后续服务和协议一起断掉，新名字也和原来的 Macintosh 区分开，「釜底抽薪的一招绝杀」。

    拖动版本号：看授权协议是否还覆盖它（按原文的说法示意）。

    在更好的硬件上，Mac OS 8 的显示效果一下子进入「高清」时代。底层仍继承自 System 7，但吸收了 Copland 项目的不少遗产，视觉和体验提升明显：加入了主题选择，多媒体软件有炫酷效果，苹果菜单依然是程序列表，类 2.5D 的图标是那个时代的流行风尚。到 Mac OS 8.5，文本抗锯齿让文字更易读，光影更柔和，界面元素更复杂，原文的评价是「不会弱于同时代的任何系统」，但「也仅仅只是不弱于对手而已」。

    文本抗锯齿是什么：把一行小字放大到像素级。关闭时每个像素只能非黑即白；开启后边缘用灰阶过渡。可以改文字、调放大倍数。
    本页补充（非原文）：Mac OS 8 的早期测试版确实以「Mac OS 7.7」命名，代号 Tempo；新的「Platinum」外观随 8.0 到来。系统级的主题切换是在 8.5 的测试版里出现的（有 Gizmo、HiTech 等主题），正式版上市前被临时拿掉，只留 Platinum，所以原文「Mac OS 8 加入了主题选择」宜理解为外观管理器打下的基础。8.5 引入了系统级的字体平滑（Font Smoothing）。[4]原文说 Mac OS 8 发布的同月乔布斯「正式任命为 CEO」：同年 7 月前任 CEO Gil Amelio 离职，乔布斯出任临时 CEO 一般记为 1997 年 9 月（本页凭记忆补充，未核对）。
    10

    Mac OS 9：争取时间的权宜之计

    第一个系列的最后一版，已经在为下一代系统预演哪些视觉元素？

    和 Mac OS 8 类似，Mac OS 9 原本应作为 8.7 发布。乔布斯回归并发布 Mac OS 8 之后，它的命运就注定了：为老硬件和老用户更新，并继续为真正的新系统争取时间。Mac OS 9 于 1999 年 10 月 23 日发布，宣传语是「有史以来网络功能最好的操作系统」。乔布斯重组的设计团队已经为新系统挑好了设计语言，OS 9 里也适当加入了一些：播放器软件的不锈钢拉丝效果、窗口元素细腻的光影起伏、搜索应用的内阴影与高度拟物的小图标。原文还指出，OS 9 里已能找到许多现代 UI 原则：有逻辑的分组、容纳多个并列分组的标签页、帮助和安装界面层级丰富的排版，以及当年令人惊艳的文字投影。

    同一控件，跨版本并排：选一种控件，看它在 System 1、System 7、Mac OS 8（Platinum）、Mac OS 9 里的示意画法。
    本页补充（非原文）：维基百科的版本表也把 8.7 列为 Mac OS 9 最初的内部版本号之一，发布日期 1999 年 10 月 23 日与原文一致。[2]原文所说的拉丝金属播放器指当时的 QuickTime 播放器；拉丝金属后来在 Mac OS X 里成为一整套窗口风格（属于本系列后续篇目的内容）。
