    Mac 视觉史（三）：浴「水」重生的 Mac 视觉美学

    从灰扑扑的 90 年代界面，到 NeXTSTEP 与 Mac OS 8 的混血 Rhapsody，再到被 iMac G3 的半透明外壳点醒、用「水滴」重做一切的 Aqua。这一页把那段 1996～2001 年的转折画成可以点、可以拖、可以调参数的线框图。

    Mac OS X 的视觉美学不是凭空出现的：乔布斯回归带来的「非同凡想」、iMac G3 半透明的邦迪蓝外壳，和 Cordell Ratzlaff 早在 Copland 时代就试过的果冻质感，在 1999 年前后汇合，才让 Mac OS X 在 DP2 与 DP3 之间脱胎换骨。[1]

    01

    90 年代的视觉美学：灰、厚、斜切

    为什么 Windows 95、OS/2、Motif、Mac OS 8，甚至 NeXTSTEP，看上去都是「一股子同样的粘腻沉重的味道」？

    原文的概括是：第一眼是灰色的窗口；定睛看细节，全是棱角分明的按钮，边缘横平竖直，厚厚的边框和斜切式的边缘让眼睛读出「突出」的效果。这是 90 年代 GUI 的最佳实践，大家都这样，遵循就行。例外只有两个：BeOS 用了更明快的配色与统一有趣的图标，NeXTSTEP 用了更「抄现实」的视觉元素，但 NeXTSTEP 的窗口本身也逃不出这套范式。[1]

    同一个窗口，六种系统。切换看标题栏、关闭按钮、滚动条和「确定」按钮怎么画。前五个都靠「左上亮、右下暗」的斜切线制造立体感；最后一个是 2000 年的 Aqua，作为对照。线框为示意重绘，不是截图。
    控件盖过了内容？原文引 Cordell Ratzlaff 的吐槽：「似乎这些元素和控制器的重要性，已经盖过了计算机真要做的事情，比如浏览内容，撰写邮件。」打开或关掉窗口里的各种「装备」、拖动边框厚度，看一个 320×220 的窗口里，真正留给内容的面积还剩多少。
    本页补充（非原文）：上面的面积占比是本页按示意尺寸现场计算的，用来把 Ratzlaff 那句话量化成一个直观的感受，不是对任何真实系统的测量。另外，Mac 一直把菜单栏放在屏幕顶端而不是每个窗口里，所以「Aqua 式」预设里没有窗口菜单栏。
    02

    缔造者 Cordell Ratzlaff：从 Copland 到 Mac OS X

    一个在 Copland 里没有话语权的设计师，怎么成了 Mac OS X 视觉美学的塑造者？

    1990 年前后的苹果仍处于全盛，研发团队在「Pink」项目下充分地挥霍经费，光做图形界面的团队就有七八个。Ratzlaff 加入苹果后参与的第一个项目是原计划中的 Mac OS 8，也就是 Copland。最终发布的 Mac OS 8 本质上只是 Mac OS 7.7，Copland 折戟沉沙，只有它的界面主题工具 Appearance Manager 衍生出的 Platinum 主题，作为正式版 Mac OS 8 的主要视觉风格延续了下来。[1]

    「我发现一个糟糕的趋势，就是项目在完成 95% 之后就罢手停滞了……当时的苹果是非常的工程技术导向的，多数的产品都是以技术为导向，至于易用和体验的愉悦感则是不必考虑的事情。」——Ratzlaff

    原文认为，Platinum 是「向世代主流视觉审美靠拢」的产物，尽管 Appearance Manager 已经探索出很多不同风格。1997 年之前，Ratzlaff 没有话语权；乔布斯回归后公司架构精简，他加入了研发下一代操作系统的行列，代号 Rhapsody，「狂想曲」。

    1996～2001 时间线。点任意节点，右边（手机上是下方）的线框会换成那一时期的界面面貌。圆点边框颜色：黑 = NeXT 血统，灰 = Platinum，蓝 = Aqua。手机上可以左右滑动时间线。
    本页补充（非原文）：时间线里的具体日期来自维基百科：苹果 1996 年 12 月收购 NeXT；Rhapsody 1997 年 5 月在 WWDC 首次演示；iMac G3 1998 年 5 月 6 日发布、8 月 15 日开售，预装 Mac OS 8.1；Mac OS X Server 1.0 于 1999 年 3 月 16 日发布；Aqua 于 2000 年 1 月的旧金山 Macworld Expo 亮相。[2][3][4] Mac OS 8 的发布时间（1997 年夏）与 Mac OS X 10.0 的发布时间（2001 年 3 月）为通行说法，本页未逐一核对原始出处。
    03

    Rhapsody 与 Mac OS X Server 1.0：混血的过渡

    NeXTSTEP 的内核穿上 Mac OS 8 的外衣，长什么样？Ratzlaff 的分栏浏览又解决了什么问题？

    Rhapsody 早期也在 x86 平台上开发，后期全部集中到 Power Macintosh，非苹果平台的版本都被砍掉。这个深度融合 NeXTSTEP 的系统被赋予了更接近 Mac OS 8 的界面：大体外观已经和 Mac OS 8 非常接近，Platinum 主题被用到各个角落；但在图标和按钮（比如文本编辑器、系统设置）上，仍带着强烈的 NeXTSTEP 特征。Mac 独占的应用，比如 QuickTime，也被移植了过来。[1]

    苹果没有直接推出 Mac OS X，而是先发布了 Mac OS X Server 1.0。它包含能运行老版 Mac OS 的「BlueBox」兼容层、大量继承自 NeXTSTEP 的功能，以及对当时各种网络服务的支持。它的文件浏览器加入了出自 Ratzlaff 设计的分栏式浏览视图：不用反复跳转，就能快速浏览多层级的文件夹和文件。

    分栏浏览 vs 一层一个窗口。在两种模式下都一路点进「Macintosh HD → 用户 → ratzlaff → 文稿 → Aqua 草图」，比一比屏幕上要摞几个窗口。
    本页补充（非原文）：「一层一个窗口」对应经典 Mac OS 的空间式 Finder 习惯（双击文件夹就在原位置打开一个新窗口）。分栏视图的思路可追溯到 NeXTSTEP 的 File Viewer 浏览器，Mac OS X 的 Finder 延续至今（「分栏」显示方式）。本页演示中的目录与文件名均为虚构。
    04

    Mac OS X DP2 与「非同凡想」

    到 DP2 为止，Mac OS X 还长着老 Mac OS 的脸。分水岭为什么出现在 DP2 与 DP3 之间？

    对外公开的测试版统称 Mac OS X Developer Preview（DP），一共发布了 4 个版本。直到 DP2，系统仍带有典型的老 Mac OS 视觉特征和交互；变化只是 QuickTime 的标志明显改了，原本冷硬沉重的图标和 UI 元素开始加入更活泼的色彩。原文说，DP2 与 DP3 之间的分水岭，是苹果整体变化带来的必然结果。[1]

    变化的种子之一是广告。重回苹果的乔布斯挑选新的广告代理商，其中有当年《1984》广告的缔造者 Lee Clow。他和团队带来了「非同凡想」（Think Different）。

    「……那种纯粹我永远都不会忘记。他坐在我的办公室里给我看那些创意，我就忍不住哭了。」——《史蒂夫·乔布斯传》
    「在此之前，苹果并不屑于做出和人不一样的东西，直到 Think Different 清晰地指明了此刻苹果的诉求。……与众不同是好的！……即使你的产品再好也不可能满足所有人，你是在为世界上最聪明的人做设计。」——Ratzlaff

    原文的判断是：在今天看来 Think Different 只是一则传奇广告，但回看 20 多年前的苹果，它是改变一切的那颗种子。1997 到 2001 年间，变化是从各个不同的地方同时发生的，所以接下来必须先谈 iMac G3。

    本页补充（非原文）：原文写作「Chia/Day 广告公司」，通行写法是 Chiat/Day（Lee Clow 所在的广告公司，1984 年的《1984》广告即出自这里；1990 年代后期已并入 TBWA，称 TBWA\Chiat\Day）。
    05

    iMac G3：先把白板擦干净

    一台电脑的外壳，怎么会成为一个操作系统视觉美学的触发点？

    「我刚到这里的时候，眼前只有一大堆产品……为什么现在我要向用户推荐 3400，凭什么说它比 4400 好呢？什么时候一个人应该入手 6500，而不是 7300 呢？……如果我都弄不清楚，用户又如何能弄清楚呢？」——乔布斯
    40 多款 → 4 款。原文：乔布斯回到苹果后做的第一件事，是把 4 个系列 40 多款产品精简成 4 款。他擦干净白板，画了一个 2×2 的表格：上面两格写「普通用户」「专业人员」，下面两格写「便携式电脑」「台式电脑」。点按钮擦白板，再点表格里的格子。
    本页补充（非原文）：左侧色块只是「4 个系列、40 多款」的示意数量，除了乔布斯原话里的 3400、4400、6500、7300 四个型号外，不对应具体机型。2×2 各格最终填入的产品（iMac、Power Macintosh G3、iBook、PowerBook G3）为通行说法，其中 iBook 要到 1999 年才推出，本页未逐一核对发布日期。

    精简之后，原 Newton 产品线、Copland 项目和 NeXTSTEP 团队的设计师与开发者重新整合到一起：工业设计向乔纳森（Jony Ive）提交原型，Mac OS X 的设计研发由原 NeXT 团队的鲁宾斯坦（Jon Rubinstein）管理，统一向乔布斯汇报。乔纳森团队反复考虑的不是芯片速度或市场份额，而是「我们想给使用者什么样的用户体验」。第一个月就做了 10 个实体原型，「鸡蛋」型最吸引人；实色塑料看起来廉价，于是有人提议半透明材质。[1]

    「我们喜欢半透明的材质，它会给人一种张扬的感觉……你知道洗澡的时候，玻璃上的水滴是怎么形成的吗？」——乔纳森

    一位设计师带来一小片蓝绿色、表面轻微磨砂的沙滩玻璃，这种颜色最终成了 iMac G3 的「邦迪蓝」（Bondi Blue）。发布会上乔布斯说它「看起来好像来自另外一个星球……一个拥有更好设计师的星球」。此时 iMac G3 内置的系统仅是 Mac OS 8.1：外壳已经是新世纪，屏幕里还是 90 年代。

    本页补充（非原文）：1999 年 1 月，iMac G3 推出五色款：蓝莓（Blueberry）、草莓（Strawberry）、橘子（Tangerine）、葡萄（Grape）、青柠（Lime）。下一章的实验台里可以把这些颜色套到 Aqua 按钮上。[4]
    06

    从 iMac 的启示到 Aqua 的美学

    「水滴」质感到底由哪些光学要素组成？少一个会怎样？

    原文说，早在 Copland 时期，Ratzlaff 在设计 Appearance Manager 时就试过类似果冻质感的界面元素，乔布斯刚回苹果时他在项目说明会上演示过，但当时没有引起重视。iMac G3 发布后，他发现了两者通透明快的质感之间的共通，开始沿着这个方向挖掘：明亮、有趣、多彩，用「水滴」质感重新设计 UI 元素。他的思路与乔纳森不谋而合：「什么东西和计算机界面毫无关联？」他想到了糖果，想到了酒。团队搜集杂志上的酒类广告，从酒液里的冰块和玻璃瓶上流转的光影中撷取细节。[1]

    2000 年旧金山 Macworld 上，乔布斯演示了这套美学，以拉丁语的「水」命名：Aqua。从窗口开关按钮到滚动条，仿佛都是用晶莹的水滴做的，被头顶的光源充分照耀，「反映出令人忍不住想舔一口的强烈质感」。

    Aqua 参数实验台。把水滴拆成六个参数：斜切（90 年代的立体手法）、顶部高光（头顶光源的反射）、底部回光（光穿过液体在底部聚起的亮带）、透明度、圆角、投影。先点预设看 Platinum → DP2 → DP3 的演变，再自己拖。颜色可以换成 iMac G3 的外壳色。
    本页补充（非原文）：「底部回光」「顶部高光」是本页为了拆解而起的名字，参数也是示意值，不是 Apple 的设计规范。默认按钮的「呼吸」脉动、红黄绿三色窗口按钮、条纹（pinstripe）背景都是 Aqua 的标志特征，据维基百科，蓝色默认按钮的脉动一直保留到 Yosemite 之前。[2]「扁平化」预设对应的是 2014 年 OS X Yosemite 之后的样子，放在这里只作对照。
    07

    Mac OS X DP3：「原教旨主义」的 Aqua

    从 DP2 到 DP3，像是「从 720P 一键升级为 4K 画质」。具体变了什么？

    原文称 DP3 大概是最「原教旨主义 Aqua 美学」的系统：水滴元素近乎不要钱地铺满界面的每个角落。经典桌面背景像在模拟水的流体感；计算器完全由水滴按钮组成，让人忍不住想戳；控制面板的标签页也是水滴式；即便是实色元素也用光影营造光滑质感。但它也没让一切都「水」：播放器仍延续早期 Platinum 时代的金属拉丝质感。直到此时，装着 DP3 的 iMac G3 才算「完全体」，从内到外遵循一致的美学。[1]

    卷帘对比。拖动滑块，在同一个窗口布局上把 DP2 时代的 Platinum 面貌刷成 DP3 的 Aqua 面貌。注意标题栏按钮、滚动条、默认按钮、窗口圆角与投影。
    水滴计算器。原文说 DP3 的计算器「让人忍不住想去戳一下」。这是一个按那种风格画的可用计算器（示意，按键布局不对应原版）。
    本页补充（非原文）：据维基百科，金属拉丝（brushed metal）质感最早出现在 1999 年的 QuickTime Player 4.0，后来在 Panther 中用得更多；Aqua 的首次正式发布是 2000 年 7 月随 iMovie 2。[2]
    08

    进入 X 时代

    苹果更看重的「另外的东西」是什么？

    Mac OS X 和 iMac G3 在当时对硬件和性能都有要求，但相比整个行业把参数奉为圭臬，苹果似乎更看重别的。原文引《乔纳森传》：「苹果公司在基本的追求之外，还有其他的渴望。」超出常规认知的疯狂尝试、彻底打破规则的创造，是 iMac G3 成为里程碑、Mac OS X 成为独角兽的核心要义。[1]

    世间所有的相遇都是久别重逢：苹果与乔布斯，NeXTSTEP 与 Macintosh，iMac G3 与 Mac OS X。进入新世纪，苹果的视觉美学重生了，苹果也重生了。不过，这仅仅是另一次长征的开始。
    本页补充（非原文）：Aqua 之后的走向（据维基百科）：Jaguar（10.2）减少透明与条纹，Panther（10.3）让按钮更平，Leopard（10.5）去掉条纹、菜单栏变灰，Lion（10.7）把果冻感换成更平的光泽，Yosemite（10.10）跟随 iOS 7 全面扁平化；2025 年苹果又在各平台推出了名为 Liquid Glass 的新设计语言，「水」的意象以另一种方式回来了。[2]
