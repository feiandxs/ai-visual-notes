Windows XP 设计史

    Windows XP：摆脱机械，拥抱自然

    Windows 95 之后几年，Windows 一直是灰暗、棱角分明的「机械」模样。XP 换上了蓝天绿草的 Luna 主题、真实照片做的 Bliss 壁纸、飘扬的旗帜徽标。这一页把这段转向拆开，让你亲手切换、拖动、点击来看。

    Whistler 项目要把 9x 与 NT 两条产品线合并成一个面向普通用户的系统，设计目标是「让操作系统更友好」：摆脱机械的僵化与灰暗，让它感觉更「自然」。途中微软试过一阵「扁平化」，最终发布的 Luna 却仍是一套塑料感的 3D 设计。[1]

    01

    设计风格的缺席

    Windows 95 之后几年的界面到底「机械」在哪里？Luna 把哪些地方换掉了？

    原文说，同当时许多操作系统一样，Windows 95 之后几年的设计风格乏善可陈：灰暗、机械，按钮棱角分明，边框突出。虽然可以改标题栏、按钮的颜色，却不能从整体上摆脱机械感。随着 Windows 95 发布，微软注意到设计对操作系统的重要性，也意识到冷冰冰的视觉风格会拉开系统与用户的距离。世纪之交，苹果等系统已开始探索新美学，微软决定跟上。

    同一个窗口、同一条任务栏，分别用 Windows 95 默认主题、XP 保留的「经典」主题与 XP 默认的 Luna 蓝色主题画出来（示意线框）。点下面的部位标签，窗口上会圈出那一处，面板里对比前后的做法。
    02

    Whistler：一个系统，两种用户

    为什么下一版 Windows 必须「更友好」？因为它要同时接住企业用户和普通消费者。

    「Whistler」项目肩负一个任务：统一 Windows 的 9x（面向普通消费者）与 NT（面向商业、企业、服务器端）两条产品线，做一个以 NT 为内核、面向主流消费者的版本。在 NT 适合商业用户的基础上，它还需要增加适当的娱乐性来吸引普通用户。

    两条产品线在 XP 汇合。点任意节点看它在这段历史里的位置（键盘可用 Tab 与 Enter）。
    本页补充（非原文）：图中各版本的发布年份按通行资料标注：Windows NT 3.1（1993）、Windows 95（1995）、NT 4.0（1996）、Windows 98（1998）、Windows 2000 与 Windows Me（2000）；Windows XP 的发布日期 2001-10-25 来自原文。Neptune 是原系列上一篇的主角，一个未发布的、基于 NT 的消费者版本。

    设计师 Gregory Raiz 大学毕业后加入微软，最初参与的正是「Neptune」项目。可用性测试里他们发现：Windows 用户完成任务的成功率更高，但被问到最喜欢、觉得更友好的电脑时，他们始终更倾向 Mac。iMac G3 半透明的弧形机身、Mac OS 柔和的光影，都让电脑显得更亲近。于是团队把「力求让操作系统体验更加友好」定为目标，又在研究后意识到融入自然元素能让 Windows 不那么机械，由此确立了理念：摆脱「机械」的僵化与灰暗，让操作系统感觉更「自然」。[1]

    03

    Windows 扁平化的开始？

    2000 年前后，微软为什么一度把按钮的 3D 效果「卸妆」？

    据雷蒙德·陈（Raymond Chen）的文章《诱饵视觉风格》，在最终视觉风格完成前，微软做了一些别的主题向公众展示以分散注意力，称为「Mallard」（野鸭，也指捕猎用的野鸭形诱饵）。原文推测这也可能包括 Whistler 前期的「Watercolor（水彩）」主题。[2]这些「诱饵」都透出同一个趋向：弱化按钮等控件的突出感，改用蓝色、黄绿色等明亮颜色，抛弃过去的灰暗色调，与 Neptune 的概念设计一脉相承。登录界面也没有多少突出的控件，「文本」占据了中心。

    启动画面：Whistler 抛弃了 Windows 2000 的机械进度条和 Win95 式加载条。Beta 1 用点状加载条，Beta 2 用四色加载条（原文作者最喜欢的启动界面之一，可惜没进正式版）。选一个版本看它的加载动画（示意重绘）。

    雷蒙德·陈在《Windows UI「睫毛膏」的演变》里解释了这次转向：Windows 从 3.0 起引入 3D 视觉元素，Win95 时大量采用，过多的结果是「对话框上的按钮有太多浓重的黑色轮廓，看起来像是刷了很差的睫毛膏」。为了抑制 3D 的滥用，微软开始在界面元素之间使用「更微妙的分隔线。分隔线变得更柔和，有时甚至完全消失」，向 2D 转变。Word 95 的工具栏还是凸起按钮，Word 97 就改成了平面按钮，只在鼠标悬停或点击时才显示立体效果。[3]

    睫毛膏用量：拖动滑块从 Windows 95 式的浓重 3D 走到 Word 97 式的平面工具栏，再到 Luna 的「微妙 3D」。把鼠标移到工具栏按钮上、按下去，看平面按钮怎样只在需要时才出现立体感。下方实时统计图中深色轮廓线的总长度。

    这种弱化突出效果、更简洁平面的设计也出现在当时微软的其他产品里，比如 Microsoft Money 2000。原文指出，它和约十年后 Windows 8 的「扁平化」颇为相似。

    04

    插曲 Candy，主角 Luna：「蓝天绿草」还是「塑料玩具」？

    诱饵之外，真正胜出的 Luna 用了什么颜色、靠什么给反馈？

    Whistler 里还有一个约制作于 2000 年 6～8 月的「Candy（糖果）」主题：标题栏按钮与水彩主题差不多，内部按钮、滚动条却很像苹果的 Aqua，据推测只用于测试。最终胜出的是「Luna（月神）」：原型设计始于 1999 年，2001 年 1 月在 CES 2001 上亮相，默认蓝绿配色，另有「银色」和「橄榄绿」。蓝色喻指蓝天，绿色喻指绿草。

    切换 Whistler 时期出现过的主题与 Luna 的三种配色（示意线框，配色为近似取色）。在 Luna 下，把鼠标移到标题栏按钮或「确定」上，它们会亮起来，这正是《Windows XP 视觉指南》说的「邀请您单击」。
    《Windows XP 视觉指南》用 4 个词概括新风格：清新、向往、多彩、简单。「标题栏和任务栏具有柔软的塑料感，鼠标悬停时按钮会亮起，邀请您单击它们。微妙的三维按钮和控件使用颜色和光线来提供更好的反馈。」「颜色用于提高可发现性并传达按钮的含义，例如绿色的『开始』按钮和红色的『关闭』按钮。告别灰色，迎接更智能、友好的颜色。」[5]

    并非所有人都买账。一些用户和媒体把 Luna 形容为「费雪玩具」（Fisher-Price，美国著名儿童玩具公司），嫌它塑料感太强、略显幼稚。微软的对策是：XP 保留前代的「经典」主题，官网也提供多种主题；主题引擎也更新了，降低了第三方做主题的难度，不过仍须修补系统文件 uxtheme.dll 才能使用非微软签名的主题。

    05

    新图标：更细致，也更难分辨

    48×48、32 位色、8 位透明度的 XP 图标，缩小以后还认得出来吗？

    与主题相配，系统图标也重新设计：48×48 像素，32 位颜色，8 位透明度，光影更细致，色彩更亮丽。但正如 Marcin Wichary 在《一千平方像素的画布》中所说，许多图标的颜色过于相近，「（颇具讽刺意味的是）就像 Windows 1.0 的情况一样，很难区分一排排看起来相似的蓝色倾斜形状，尤其是当图标缩小时。」[6]

    六个以蓝色为主的示意图标（本页按 XP 风格自绘，不是原图）。拖动尺寸滑块，图标先在该尺寸下光栅化，再放大显示每一个像素；打开「去色」，只剩明暗时它们几乎是同一团蓝灰色块。下方用 CIELAB 色差 ΔE 现场计算这些主色彼此有多接近。
    06

    走失的「扁平化」

    水彩主题和 Luna 原型都偏平，为什么最终的 Luna 又回到了 3D？

    雷蒙德·陈说 Windows XP 也加入了「扁平就是好」的潮流（比如资源管理器的「任务窗格」），可最终的 Luna 减少了扁平元素，《指南》里用的也是「3D 按钮」这样的词，今天人们仍把 XP 归为「拟物化 3D 设计」。原文作者没找到详细解释，给出一种说法：当时仍有相当多人没接触过电脑，界面需要模拟现实才能让更多用户适应；而苹果 Mac OS X 的 Aqua 把拟物推向了新的高度。雷蒙德·陈在 2004 年的文章结尾问：「当人们厌倦了平面的僵硬感时，3D 会强势回归吗？」[3]他的预感在 XP 的下一代成了现实。扁平化并没有消失，而是在 Media Center 等产品中若隐若现，约十年后才有了自己的名字「Metro」（微软称其正式名称是 Microsoft Design Language，Metro 只是代号）。

    扁平与立体的钟摆：横轴是年份，纵轴是「3D/拟物程度」。纵向位置是本页按原文描述做的示意定位，不是测量值。点任一个点，看原文怎么说它。
    本页补充（非原文）：图中「Windows Vista / Aero（2007）」与「Windows 8（2012）」两个点的年份为通行资料；原文只说 3D 在 XP 的下一代回归、扁平化约十年后以 Metro 之名出现，具体是下一篇的内容。
    07

    告别纯色背景：自然之「极乐」

    一张草地照片，为什么恰好配得上 Luna？

    Windows 3.x 就支持设置桌面壁纸，但 9x 的默认壁纸仍是纯色，NT 系列只是用 Windows 徽标做壁纸（Windows 2000 甚至也是纯色）。Whistler 决定用一张真正的照片凸显个性，主题选了大自然；设计经理 Rob Girling 的用户研究也发现人们普遍偏爱风景壁纸。摄影师 Charles O'Rear 1996 年 1 月去看女友 Daphne Irwin 时，在加州索诺玛（Sonoma）的公路旁拍下一张草地照片，原名「Bucolic Green Hills」。XP 产品设计主管 Jen Shetterly 看中了它：既符合 Luna 的配色，又与 Windows 95 起采用的「云」元素不谋而合。2000 年微软通过 Corbis 买下照片，命名为「Bliss（极乐）」。[1][9]

    切换各版本的默认桌面（示意）。在 XP 的 Bliss 上点天空、云、草地，看这块颜色离 Luna 的哪个界面色最近（ΔE 由页面现场计算；Bliss 的颜色是本页示意取色，并非原图像素）。

    同样出自 O'Rear 的「红月沙漠（Red Moon Desert）」也曾被用作 XP 的默认壁纸，后来成为内置壁纸之一。Girling 还计划给 XP 专业版用办公楼照片做默认壁纸，被高层否决，可能因为 Bliss 已大量出现在营销中。不同语言版本对 Bliss 的命名也不同：荷兰语版叫「Ierland」，葡萄牙语（葡萄牙）版叫「Alentejo」。Bliss 结束了 Windows 桌面默认纯色的历史，此后壁纸成了每一版展示设计风格的舞台。27 年后，另一个系统的设计团队来到这片土地，「索诺玛」成了 macOS Sonoma 的名字和壁纸取景地。

    08

    鲜明的「旗帜」：徽标的变化

    四色徽标是「窗口」还是「旗帜」？XP 选了旗帜，并让它飘起来。

    微软委托 Frog Design（也参与过早期苹果电脑的设计）为新版本设计徽标，要求「保持其在悠久历史中积累的品牌资产，同时也要向更灵活、用户友好的品牌演变」。Frog 认为经典的四色排列既是「打开世界的窗口」，也是「探索和发现的旗帜」，于是设计了 50 个新徽标，有偏「窗口」的也有偏「旗帜」的；最终由 Cathy Potter 设计的 3 种交给微软。新徽标完成了从机械方形旗帜到飘扬的自然旗帜的转向。Frog Design 还设计了 XP 的媒体播放器等组件界面。

    拖动滑块，从 Windows 95～2000 时期的徽标（黑色描边、左侧像素拖尾）过渡到 XP 的徽标（去掉描边，更圆润的飘动与高光）。两端都是本页的示意重绘。最后一个按钮是原文留下的「后话」。
    本页补充（非原文）：原文参考资料中该设计师作品页的域名是 caseypotterdesign.com，名字可能应为 Casey Potter；本页未能核实，正文按原文保留。原文结尾的「灵魂拷问」（你叫「窗户」，为什么徽标用旗帜？）指向 Windows 8 的徽标重设计，据通行资料出自 Pentagram 的 Paula Scher，本页未逐一核对。
    09

    「eXPerience」：除了外观，还改了什么

    开始按钮挪到角落、任务栏分组、按任务排的控制面板，各自解决什么问题？

    2001 年 10 月 25 日，Windows XP 正式发布。「XP」来自「eXPerience（体验）」，这一版的变化集中在用户体验上。开始菜单变成双列，左侧显示最近使用的程序，也可固定常用程序；任务栏可以把同一程序的多个窗口合并成组；「开始」按钮延伸到了屏幕角落，直接点任务栏一角就能打开菜单，这应用了菲茨定律：目标越远、越小，鼠标捕获它的时间越长，而屏幕四角最容易到达。

    菲茨定律与屏幕角落：在「屏幕」里任意点一下放置鼠标，再选「瞄准点击」或「直接甩向左下角」。按原文的说法，Win95 的开始按钮与屏幕边缘之间留有空隙，XP 的按钮延伸到了角落（示意几何）。
    本页补充（非原文）：菲茨定律由 Paul Fitts 于 1954 年提出。人机交互里常用 MacKenzie 的 Shannon 形式：MT = a + b · log₂(D/W + 1)，D 是到目标的距离，W 是目标沿运动方向的宽度，log 项叫难度指数 ID（单位 bit）。屏幕边缘会挡住鼠标，贴边的目标在那个方向上相当于无限宽，这就是「角落最快」的原因。演示里的 a、b 取 0.1 s 与 0.15 s/bit 仅作示意。[12][13]
    任务栏分组：拖动滑块增加打开的窗口数（来自 4 个程序），比较不分组与分组时任务栏的样子。
    本页补充（非原文）：XP 默认在任务栏按钮挤不下时才把同一程序的窗口合并（「分组相似任务栏按钮」选项），演示按这一行为建模；按钮的最小宽度等数字为示意，本页未核对 XP 的确切阈值。

    控制面板借鉴了 Neptune 项目的「引导式导航」，按「任务」编排设置项目，也可切换回「经典视图」直接显示全部选项；资源管理器的「任务窗格」也是同样的思路。另一个细节：从 XP 起，全新安装后的桌面默认只有一个「回收站」图标（不少人以为默认还有「我的电脑」，可能是受非原版 Windows 影响）。

    控制面板：任务视图与经典视图。选一个你想完成的事，看两种视图下各要点哪里。分类与项目名称按 XP 中文版的常见叫法示意。
    10

    结尾：从「别人想要」到「我想要」

    用户测试里，人们夸 Luna 的方式透露了什么？

    雷蒙德·陈在《Luna 的外观》里记下了用户测试中的反应。[4]
    对 Luna 的反应「哇，这对 我爸爸 / 我的员工 / 我女儿 来说会是一个很棒的 UI。」人们并不认为自己会认可这套 UI，他们认为别人会接受它。
    对下一套 UI 的反应「哇，这对 我 来说会是一个很棒的 UI。」这套 UI 就是下期的主角：Aero。
    XP 用蓝天、绿草、飘扬的旗帜和一张真实的草地照片，把 Windows 从灰色的机械感里拉了出来；它试过扁平，又退回塑料感的 3D，并把「下一步往哪走」的问题留给了 Longhorn。

    原文结尾预告：XP 的下一代（代号 Longhorn）是 Windows 历史上开发周期最长的一代（原文注：指开发周期而非发布间隔），「疯狂到，到最后，必须从头再来」。
