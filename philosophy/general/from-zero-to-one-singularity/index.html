    哲学上从 0 到 1 这个奇点
    是如何发生的？

    答主「高大早」先用公理化集合论里的冯·诺伊曼序数给出数学的回答，再顺着拉康把它推到主体、精神病和「父姓的功能」。同一问题下另一位答主则反问：为何有 0，而不是连 0 都没有？

    核心线索：0 是空集，1 是「装着空集的集合」。但「空集」这个 0 本身来自一次自指——它既在体系之内，也在体系之外。

    01

    数学的答案：0 是空袋子，1 是装着空袋子的袋子

    高大早：公理化集合论中的冯·诺伊曼序数就解决了这个问题——定义 0 为不包含任何元素的集合（空集），定义 1 为「包含一个空集」的集合。

    点「下一步」，看自然数怎样一个接一个地从空集里长出来。规则只有一条：n + 1 := n ∪ {n}（新来的把以前的老东西挨个儿全吃了）。
    • 0 := ∅；1 := {∅}；2 := {∅, {∅}}；3 := {∅, {∅}, {∅, {∅}}}……每个数都「装着」它前面所有的数。
    • 高大早注：这原本被他写成康托尔集合论，「但显然是不对的，评论区有我狡辩的过程」。
    02

    拉康：这个 0 其实是一个自指悖论

    如果没有预先定义的数学体系，0 根本不可能。所以 0 是数学体系本身在其内部的在场——一个「外密性」的规定：既在体系之内，也在体系之外。

    体系画成一个圈。0 不是圈里普通的一个点，而是圈本身「折进去」的那一点：既在内，又在外。点击「推演」看结论怎么一步步推到「形式体系本质上是自解构的」。
    • 拉康进一步认为：所有形式体系都是这样被规定出来的，所以都不完备，都有一个外密性的规定（0）。
    • 这意味着形式体系本质上是「自解构」的——这就是拉康的解构主义转向。
    03

    主体是一种「运作效果」：朝向 0 的强迫性重复

    语言系统也是一个在内部坍缩、自指的形式体系。这个运动留下一个不可化约的剩余（0 之前的那个东西），而人的自我，就是朝向它的无限递归运动本身。

    小球一次次朝「0 之前的东西」冲去，每次到 0 就被象征律令挡回，于是再来一次。精神分析把这叫作强迫性重复。
    • 象征（形式体系）是一种律令，它禁止你回到 0 之前的那个东西。
    • 所以主体本质上是朝向纯粹否定性的、无法停息的「无-意识」——用时髦的词说，「反物质」或「负空间」。
    04

    两个 bug：正常人靠「镜像」回避自指，精神病人少了这一层

    语言系统有「从 0 到 1」这个 bug。所谓正常人，是在 bug 中通过另一个 bug（镜像认同）去误认，从而使自己正常；精神病人缺少第二个 bug，于是产生幻觉和妄想。

    切换两种情形，看同一个「无意识的主体」在语言系统里的不同位置。
    • 神经症（正常人）：经由镜像认同，分裂出一个在语言之内的自己；给自己贴一堆标签，却隐含地认为最本真的自我无法被任何标签定义——这种纯粹否定性反过来定义标签，这就是能动性（agent）的来源。
    • 精神病：分裂不出镜像自我，无意识的主体直接跌入语言系统，语言系统本身对他「显现在场」——他会发觉「语言系统在对着他说话」，这就是幻觉与幻听的由来。
    • 视觉的例子：你不能直接看见物，只能看见「可见之物」，即视觉系统本身。精神病人因为站在语言之外，能「直接看见视觉系统本身」——答主截图中那个人「看见自己的眼睛」，看见的其实是视觉系统。
    05

    人为什么会成为精神病？「父姓的功能」被除权

    一个人能在语言系统中获得自己的位置，很大程度上是接受了「父姓的功能」：你爹和你之间不存在可观测的自然联系，只能通过「赐名」这个行为在语言系统之内建立联系。

    赐名把主体「拉进」语言系统并诱发分裂；当这个功能出问题（被除权），主体就得不到位置。典型案例：施列博案。
    • 正是「赐名」这个功能诱发了主体向语言系统内部的分裂过程。
    • 所以精神病常和性别认同的错置同时发生——和爹的关系决定了主体在性别认同上的位置。
    06

    另一位答主：更重要的不是 0 到 1，而是「为何有 0」

    对应到集合论：当什么都没有的时候，凭什么对「空空如也」做一次「套袋儿」是合法的？答案出人意料——空集根本就不「空」。

    空集至少有三种构造方式，每一种都把一类「卡 bug 的对象」排除出去。点一下看每个袋子里本来想装什么。
    • 空集的存在可以直接用空集存在公理保证；也可以先由等式公理暗示「至少存在一个集合 Ω」，再用分离公理构造 {x ∈ Ω | x ≠ x}。
    • 从构造方式看，空集是个「垃圾桶」：装着当下公理体系排除在外的对象，但它们在空集内部已经被压平，所有矛盾特性都等价了——抽象地说，可以叫它「不可能性」。
    • 如果允许更换公理体系，垃圾桶就变成「回收站 / 黑名单」：换一套公理后，原来被 ban 的对象可能被恢复（例如能讨论真类的 NBG 集合论）。
    07

    两套造数方案，以及「套袋之前」的那个东西

    公理化集合论「假装自己非常圆满」，并不在乎空集内部的矛盾有多丰富，反而拿空集当根基去造自然数。历史上有两套方案。

    左：策梅洛序数——一直复读「套袋儿」，套了几层就代表几。右：冯·诺伊曼序数——后来各种公理化集合论普遍采用的方案。拖动 n 对比两种写法。
    • 策梅洛：0 := ∅，n + 1 := {n}。冯·诺伊曼：0 := ∅，n + 1 := n ∪ {n}。
    • 类比到拉康：在空集「套袋」之前那个空空如也的「 」，被称为客体小 a——未被压抑的矛盾集合体、未被锚定为「无」的存在；齐泽克把它本体论化，称作「少于无（Less Than Nothing）」或「den」，作为其本体论的初始对象。
    两位答主殊途同归：数学用「空集 → {空集}」造出 0 和 1；而哲学追问的是，把「空空如也」套上袋子的那一下——0 本身——是怎么被允许的。拉康说它是体系的自指，另一位答主说它是把矛盾压平后的「不可能性」。
