37% 法则
    最优停止 · Optimal Stopping

    37% 法则：什么时候该停止寻找？

    它来自一道叫「秘书问题」的数学题：候选人一个个来，每个都得当场拍板，拒绝了就不能回头。数学家算出了一条漂亮的规则，但它的适用范围比网上流传的窄得多。

    先看前 37%，一个都不要，只记住最好的那个有多好；之后第一个超过它的，立刻拿下。这样选中「全场最佳」的概率也约等于 37%。[1][2]

    本页以一则个人笔记为起点，结合公开文献与本页自带的模拟器写成；所有数字在页末列出处。术语首次出现附英文。

    01

    秘书问题的四条规则

    规则少一条，答案就不再是 37%。

    秘书问题（Secretary problem）的标准设定[1]。点击卡片看它对应的现实含义。

    还有一条隐含规则：候选人的到来顺序是完全随机的。如果好的总在后面，策略就不一样了。

    02

    停得太早，或停得太晚

    不「看」一会儿，就不知道什么算好；看太久，好的已经被你放走了。

    同一批候选人，三种停止时机。黄框 = 全场最佳。
    03

    看它跑一遍

    前 37% 只抬高「标杆」；之后第一个越过标杆的人被录用。

    20 位候选人随机排列。橙色 = 观察期（只记录，不录用），紫色 = 刷新了标杆，绿色 = 录用，红色 = 全场最佳被错过。多跑几次，会看到三种结局。
    04

    为什么偏偏是 37%

    让电脑替你面试几十万次：每个观察比例都试一遍，画出成功率曲线。

    横轴 = 观察期占总人数的比例 k/n，纵轴 = 选中全场最佳的概率。灰点是蒙特卡洛模拟，紫线是精确公式，青色虚线是极限曲线 −x·ln x。[1][12]
    05

    推导只要四步

    把「第 i 个人是最佳、且他能被选中」的概率加起来，再让 n 趋于无穷。

    策略：跳过前 r−1 个，之后录用第一个比他们都好的人。[1] 点击「下一步」逐步展开。
    n 很小时，最优的 r 和成功率（精确值）[1]。n=100 时最优是跳过前 37 个，成功率 37.10%；本页用同一公式算出。
    06

    两个 37% 不是巧合

    观察比例是 1/e，成功概率也是 1/e，而且几乎不随人数变化。

    用最优策略时，选中全场最佳的概率随 n 的变化。n 越大越接近 1/e ≈ 36.8%，但从来不会低于它。[1]

    对照：如果闭着眼睛随便选一个，选中最佳的概率是 1/n。100 个人里就是 1%。37% 是靠「先看后跳」挣来的。

    换一条规则，数字就变

    对方可能拒绝你？可以回头？知道绝对分数？每种情况都有人算过。

    橙色 = 该先观察（不出手）的比例，青色 = 最终选中最佳的概率。点击一行看说明与出处。
    08

    真人实验：大家都停得太早

    十几项实验得到同一个结果：人们在远未看到 37% 时就出手了。[10][11]

    示意图：最优停止点 vs 实验中观察到的典型停止点分布。曲线为示意，不是某一项实验的原始数据。
    • 为什么会这样：每多看一个候选人都有代价（时间、精力、焦虑），而数学模型假设看人是免费的。[1][11]
    • 一个有用的推论：如果你知道自己会提前出手，刻意逼自己「多看几个」通常是对的。

    四个问题，判断能不能用

    12

    一句话带走

    37% 法则回答的是「该看多少个再出手」，不是「看了多少就该放弃」。当候选人依次出现、拒绝不可回头、目标是全场最佳、人数大致已知时，先看 1/e，再抓第一个超过标杆的；换掉任何一条，就去查对应的变体。
