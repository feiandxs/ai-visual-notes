广义坐标为什么"不是时间的函数"？

拉格朗日方程里写着 ∂L/∂q̇，可 q̇ 不就是 dq/dt 吗？为什么物理书又说 q 和 q̇ 是两个独立的变量？答案是：同一个符号 q，在两个不同的场合里，指的是两样东西。

原文：東雲正樹 在知乎问题「拉格朗日方程中，为什么说广义坐标不是时间的函数？」下的回答（811 赞），2022 年 7 月；附 Skadiologist 的进阶回答 · 本页为可视化讲解
01

第一层：一个状态，就是一组数字

分析力学用广义坐标 qi 和广义速度 q̇i 刻画系统。一组确定的取值，唯一对应系统的一个确定状态。它们就是 2s 个数，仅此而已。

以 q 和 q̇ 为坐标轴架起"态空间"。每点一个状态。点"随机取一个状态"，看它只是两个数。

这里还没有引入时间。q 不是 q(t)，q̇ 也不是 dq/dt，它们"就俩数字罢了"。

  • 对无约束质点系，qi 可以是某质点的 x 坐标，q̇i 就是它在 x 方向的速度大小。
  • 这套理论能研究一切物理系统，刻画系统的参数不一定是"坐标与速度"，所以才叫广义坐标与广义速度：本质是"刻画系统状态的参数"。
02

既然有 2s 个参数，为什么不叫 2s 个"坐标"？

因为 q̇i 和 qi 始终有联系：q̇i 是"沿 qi 坐标轴方向的速度大小"。但这个联系不是"求导"，两者各自仍只是一个数。

速度矢量按坐标轴分解：q̇1 是沿 q1 轴的分量，q̇2 是沿 q2 轴的分量。进阶写法里它是 v = Σ vi ∂/∂qi，基矢 ∂/∂qi 对应第 i 个坐标。

03

第二层：引入时间，坐标才变成函数

一段确定的演化过程 = 给每个时刻指定一个状态。于是在这条"演化路径"上，qi 和 q̇i 才成了时间的函数 qi(t)、q̇i(t)。

态空间里有无穷条路径，真实发生的只有一条。只有在真实路径上，q̇(t) 才同时等于 dq/dt。

此刻读数

—

q̇(t) 等于 dq/dt 吗？

—

随意选的路径：q̇(t) 和 q(t) 各自是任意函数，彼此不必有导数关系。真实路径：q̇(t) 恰好是 q(t) 的导函数（这里用简谐振子 q = cos t，q̇ = −sin t 作示例）。

  • 时间 t 在这个框架里也只是一个参数，但它不用来刻画状态，而用来给过程编号。
  • "为 q(t)、q̇(t) 选定函数形式" ⇔ "指定一条路径"。
04

哪条路径是真的？作用量原理

拉氏量 L 是 q(t)、q̇(t) 的复合函数；作用量 S 是 L 的泛函。一条确定的路径 → S 的一个确定值。真实路径使 S 取极值。

固定两端 q(0)=0、q(1)=1，用参数 a 改变路径形状 q(t) = t + a·sin(πt)。拖动 a，看 S 怎么变。（示例取 L = ½q̇²，自由粒子）

左：候选路径。右：每条路径对应的 S 值；a = 0（直线）处 S 最小，就是真实路径。"所以最后还是归结到函数取极值的问题上去了"（原文注：其实是泛函）。

05

进阶视角：位形空间 M 与切丛 TM

Skadiologist 的回答用了更准确的语言：q 是位形空间 M 的坐标，v 是切丛 TM 的纤维坐标；路径 γ 是 ℝ → M 的映射，求导后才"提升"到 TM 里。

L : TM × ℝ → ℝ，坐标形式 L(q¹…qⁿ; v¹…vⁿ; t)。此时没有任何路径，"vi = q̇i"无从谈起。指定路径 γ(t) 后，(γ, γ̇) : ℝ → TM 才把它提升到切丛，这时才能写 q̇i(t)。

  • 切丛中不是所有路径都能写成 (q(t), q̇(t)) 的形式，这正是必须区分 vi 和 q̇i 的原因。
  • 所谓 ∂L/∂q̇i 是滥用记号，正确写法是 ∂L/∂vi：对切丛坐标求偏导，与"对时间求导"无关。
  • 東雲正樹的表述：以全体 qi、q̇i 为轴架起实 2s 维的态空间，每个点一个状态；一条演化路径就是其中一条以时间为参数的曲线。
06

偏导数 ∂L/∂t 和全导数 dL/dt 完全是两回事

沿路径代入后得到的 𝓛(t) = L[γ(t), γ̇(t), t] 是 ℝ → ℝ 的函数；对它求导才是"全导数"，两者靠链式法则联系。

∂L/∂t　偏导

L 是 TM × ℝ 上的函数，固定 q、v，只动 t 坐标。不涉及任何路径。

d𝓛/dt　全导

先把路径代进去得到 𝓛(t)，再对 t 求导。路径上 q、v 也在随 t 变。

d𝓛/dt = ∂L/∂t + Σi ( ∂L/∂qi · q̇i(t) + ∂L/∂vi · q̈i(t) )

链式法则里的每个偏导都是在 TM × ℝ 上算好、再沿路径 [γ(t), γ̇(t), t] 取值的。

07

所以："懂的都懂"

物理书把两层含义都写成 q，是符号的滥用。但既然大家都这么用，它就不容易出错。要继续学物理，就得掌握这种思维模式。

写 ∂L/∂q、∂L/∂q̇ 时

q、q̇ 是态空间的坐标，彼此独立，不是时间的函数。

写 d/dt (∂L/∂q̇) 时

已经沿某条路径代入，q(t)、q̇(t) 是时间的函数，且 q̇ = dq/dt。

Euler–Lagrange 方程 d/dt(∂L/∂q̇) − ∂L/∂q = 0 把两层含义塞在一行里：先在态空间求偏导，再沿路径对时间求全导。
