诺顿穹顶：牛顿力学也会"不确定"？

把一个小球放在一个特殊形状的穹顶顶点上，牛顿第二定律竟然允许它"在任意时刻无缘无故滑落"。这到底是物理出了问题，还是数学在开玩笑？

01

「悖论」何在？

同一个初始状态（球静止在顶点），牛顿方程却有不止一个解：永远不动，或者在任意时刻 T 开始滑落。

穹顶形状 h = (2/3g)·r3/2。选一种解，再按"演化"看小球怎么动。

t = 0.0 s · r = 0（小球在顶点）

运动方程： d²r/dt² = √r　　初始条件： r(0)=0, ṙ(0)=0
  • 解 ①：r(t) ≡ 0，小球永远停在顶点。这是我们直觉里"唯一"的答案。
  • 解 ②：r(t) = 0（t ≤ T），r(t) = (t−T)4/144（t ≥ T）。T 可以是任何数，每个 T 都是方程的合法解，也都满足同一个初始条件。
  • 没有任何外力、没有任何扰动，方程本身就"允许"小球在任意时刻出发。这就是「悖论」。
02

为什么解不唯一？关键在那个 √r

常微分方程"初值确定、解唯一"是有条件的：右边的函数要足够光滑（Lipschitz 条件）。√r 在 r = 0 处斜率无穷大，恰好不满足。

左：普通的 f(r)=r，原点处斜率有限。右：f(r)=√r，原点处斜率发散。

解的唯一性定理（Picard–Lindelöf）要求 f 满足 Lipschitz 条件；√r 在 0 附近不满足，于是唯一性不再有保证。

同一初始条件下的"解族"：r = 0 这条线，加上在不同 T 分叉出去的无数条四次曲线。

每一条曲线都是 d²r/dt² = √r 的严格解，且在 t = T 处与 r = 0 光滑衔接（位置、速度、加速度都连续）。

  • 穹顶形状 r3/2 是被特意设计出来的：它让沿面切向的加速度正好等于 √r。换成普通的球面或抛物面，方程右边是光滑的，解就唯一。
  • 所以悖论的根源不在"牛顿定律错了"，而在"这个方程恰好落在唯一性定理的盲区"。
03

如何理解诺顿穹顶悖论？

原文把讨论分成三层：数学上发生了什么，物理上这个穹顶是否真实，以及微小扰动下会怎样。

数学层面

这是一个初值问题"解不唯一"的例子。牛顿第二定律本身没有矛盾，是方程的非光滑性让决定论失效。

物理层面

r3/2 的顶点是一个曲率发散的尖点（见下节）。真实材料做不出"数学上精确"的顶点，小球也不是质点。

微扰层面

原文 2022-08-14 更新专门计算了微扰情况并讨论"实验上能否证实"。专栏里还有一篇追问：无穷小微扰下，什么样的「穹顶」滑落时间是有限的？

评论区的三种声音（非作者观点，供对照）

"力从哪来？"

有评论质疑：让球滑落的竖直分力从何而来？是外力、合力还是支持力的分量？——这是对受力分析的追问。

"时间不是先验的"

有评论提出：若把时间看成系统状态 (x, p) 的反函数，而不是把 x、p 当成 t 的函数，静止态的奇异解就消失了。

"这就是概率"

有评论认为：任何"理想实验"只能给出统计结果；牛顿定律可改述为"合外力为零时速度为零的概率为 1"。

04

曲率发散？小球会"飞起来"吗？

原文附录对这个问题做了具体计算。这里只展示一个可以直接算出的数学事实：穹顶顶点的曲率是无穷大。

h(r) = c·r3/2 的一阶、二阶导数。二阶导 ∝ r−1/2，在 r → 0 时发散。

曲率发散意味着：顶点附近"弯得无限急"。一个有大小的真实小球无法贴合这样的尖点，这也是"物理上理想化"的具体含义。关于小球是否会脱离曲面（"飞起来"），请以原文附录计算为准，本页不替作者下结论。

h = c·r3/2　→　h′ = (3c/2)·r1/2　→　h″ = (3c/4)·r−1/2 → ∞ （r→0）
05

总结

决定论不是牛顿定律"自带"的，而是"定律 + 足够光滑的方程"共同给出的。诺顿穹顶把这个前提暴露了出来。

特殊形状h ∝ r3/2
→
方程非光滑右边出现 √r
→
唯一性失效同一初态多个解
→
看似悖论"无故"滑落
→
解释数学盲区 + 物理理想化
  • 它是数学上合法的构造：每个解都严格满足方程。
  • 它是物理上理想化的构造：曲率发散的尖点、质点小球、零扰动，三者在现实中都不成立。
  • 有价值的不是"牛顿错了"，而是看清：决定论需要前提。
